# TREENA · 每日行动与复盘

已恢复用户提供的 V9 原版布局、日历、工作区、生活区、优先级、回收站和阅读模式。原版历史复盘经用户明确确认后一并公开。

index.html 为独立页面，不加载旧版 app.js、style.css 或 data.json。编辑自动保存在当前浏览器，使用“导出全部备份”迁移记录；每日复盘可使用“导入 AI 复盘 JSON”。浏览器编辑不会自动同步 GitHub，需在有仓库写入权限的会话中更新页面内嵌记录。

修复原版删除和撤销处理器中重复插入历史记录的代码。已通过模拟 DOM 验证初始化、标签切换、阅读模式、添加、删除和撤销；未做真实浏览器交互验收。
