# Treena · AI 学习工作台

无需构建的静态个人工作台，包含 8 个 AI 工具的学习地图、9 项实践路线、每日复盘、JSON 导入导出与浏览器本地保存。

## 使用与部署

直接打开 index.html 即可使用。将本目录文件上传到 GitHub 仓库根目录，在 Settings → Pages 中选择 Deploy from a branch、main、/ (root)，等待部署完成后使用 GitHub 返回的实际网址。

Tailwind 和 Font Awesome 通过 CDN 加载，首次访问需要联网。无后端、无模型接口、无账户系统。

## 数据保存规则

- 编辑立即保存在当前浏览器 localStorage；不会自动同步其他设备或 GitHub。
- 首次在网页打开且没有本地记录时，读取仓库的 data.json。已有本地记录时优先保留本地内容，避免覆盖未上传的复盘。
- 导出得到 data.json。导入会完整替换当前数据，操作前请导出备份。
- 若需要加载更新后的仓库数据，请从仓库下载 data.json，再通过页面的“导入数据”按钮导入。
- 每天复盘后导出 data.json，上传替换仓库同名文件，GitHub Pages 部署完成后即可提供该版本。
- GitHub Pages 通常是公开网页。复盘上传前去除个人隐私及业务敏感信息。浏览器数据不会因访问网站而上传。

## 给 ChatGPT 的每日复盘提示词

请根据今天的对话整理我的学习复盘，并在我提供的最新 data.json 基础上更新数据。保留已有全部 tasks 和其他日期的 reviews，同一天按 date 更新，禁止虚构成果和学习时间。输出完整且可解析的 JSON，不添加注释。schemaVersion 固定为 1；tasks 是已完成任务编号数组，合法编号为 0-0 至 0-2、1-0 至 1-2、2-0 至 2-2。reviews 每条包含 date（YYYY-MM-DD）、minutes（0 到 1440 的整数）、tool（综合或八个工具名称之一）、done（非空）、lesson、next。上传前核对仓库最新版本以保留其他设备的数据。若本次会话有 GitHub 写入权限且我已授权上传，请更新指定仓库的 data.json 并报告实际提交结果；没有权限则生成文件供我手动导入和上传，不要声称已上传。
